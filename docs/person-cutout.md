# 人物切り抜き

背景・前景のカットを右クリック → 詳細編集 →「人物切り抜き」で使用します。画像と動画に対応しています。

1. 実写向け RVM MobileNetV3、またはアニメ向け SkyTNT Anime Segmentation / ISNet を選択します。
2. 動画の場合は解析枚数／秒を指定し、「人物切り抜きを実行」を押します。カット内で再生する範囲だけを解析し、作成済み部分は再利用します。追加する枚数、ダウンロード、初期化、解析済み枚数と進捗を表示します。「処理を中止」で中断できます。
3. 作成後に「人物のみ表示」「人物を削除（背景に穴が開く）」を選ぶか、「文字を人物の後ろへ」「前景を人物の後ろへ」をONにします。作成直後は通常表示です。
4. 「適用」でカットに保存します。

人物の削除はマスク部分を透明にします。隠れていた背景を生成・補完する機能ではありません。画面全体の背景色や下の素材が穴から見えます。

## 素材への追従と保存

マスクは素材の時刻・座標を基準に保存します。作成対象はそのカットで再生するフレームだけです。素材の位置、サイズ、回転、演出を変更しても追従します。同じ素材指定のままカットの演出をリセットしても保持します。素材を変更した場合は旧素材のマスクを適用しません。

動画のカット終了時間・再生時間・再生開始位置を変更した後は、人物切り抜きを再実行してください。同じ素材・モデル・解析枚数／秒のマスクから不足分だけを追加します。短くした範囲のマスクも削除せず、後で再び延長した際に再利用します。ループで同じ素材フレームを繰り返し再生しても、同じフレームを重複解析しません。すべて作成済みの場合はモデルの読み込み・推論を行いません。

例えば素材側の10〜12秒を作成した後に10〜15秒へ延長すると、12〜15秒のフレームだけを追加します。モデルや解析枚数／秒を変更した場合は、現在の再生範囲を作り直します。範囲は解析枚数に応じたフレーム単位で判定します。未作成の範囲は別時刻のマスクで代用せず、表示処理をONにした書き出しでは再実行を求めます。

解析結果は最大辺512pxの透過PNG列としてブラウザの素材用ストレージに保存し、カットには参照と表示設定を保存します。通常のプレビュー・書き出しではモデルを再実行しません。動画は解析時の枚数／秒でマスクを選ぶため、少ない解析枚数では速い動きでずれることがあります。

プレビューでは、各マスクを次の解析時刻まで表示し、次の2フレームを先読みします。次のPNGを読み込んでいる間は直前のマスクを維持して、マスクなしの表示へ切り替わるちらつきを防ぎます。書き出しではその時刻のマスクを読み込み終えてから描画します。まだ生成していない範囲には、この読み込み待ち用の代替マスクを適用しません。

「保存」の素材入り `.jizuraichi` ファイルにはマスクも含まれ、別のブラウザでも復元できます。ストレージの削除・自動削除に備えてファイルを保存してください。ブラウザへの保存に失敗した場合は既存の素材と同様、セッション中のみ保持します。After Effects向けの構成データには人物マスクの描画機能は含まれません。

## ダウンロード・負荷

| モデル | モデル容量 | ブラウザでの実行 |
| --- | --- | --- |
| RVM MobileNetV3（公式TFJS int8版） | 約4MB | TensorFlow.js 4.22.0 / WebGL。利用不可の場合はCPU |
| SkyTNT Anime Segmentation（ISNet） | 約176MB | ONNX Runtime Web 1.22.0 / CPU（WASM、1スレッド） |

モデルと推論ライブラリを初回利用時に外部から取得します。素材、解析結果をサーバーに送信する処理はありません。モデルはCache Storageに保存し、同じモデルの次回利用時に再使用します。容量不足、プライベートブラウズ、ブラウザによる削除などでキャッシュできない・消える場合は再取得します。ライブラリは通常のHTTPキャッシュを使用するため、完全なオフライン動作は保証しません。

解析はWeb Workerで行い、操作画面への負荷を抑えます。動画はカット内で必要な未作成フレームだけを解析するため、不足する再生範囲の長さと解析枚数に比例して時間・保存容量が増えます。ISNetは特にメモリ・CPU負荷が大きく、長いカットは解析枚数を下げてください。iPhone実機での動作・速度は未検証です。

ISNetのWebGPU実行は、使用するモデルのMaxPool演算に対応していないため採用していません。RVMは新規解析する連続区間内でフレーム間の状態を引き継ぎます。解析済みフレームを飛ばして別の追加区間を解析する際は状態を初期化します。ISNetは各フレームを独立に処理します。

## 開発時の検証

`node dev/person_cutout_test.cjs` はモデルをダウンロードせず、日英UI、4種類の表示、素材への追従、再生時刻・ループ、素材入り保存を検証します。

`node dev/person_cutout_range_test.cjs` は実際の動画シークと保存処理に、決まったマスクを返すテスト用ワーカーを組み合わせ、カット内の範囲、不足分だけの追加生成、ループの重複除去、短縮時の保持、従来形式の再利用、キャンセル、日英の詳細編集画面での再実行を検証します。

`node dev/person_mask_playback_test.cjs` は30fpsの動画と異なる解析枚数のマスクを使い、PNGの読み込みを意図的に遅らせ、4種類の表示処理、キャッシュから削除されたフレーム、ループ、未生成の範囲、書き出し時の正確なフレームを検証します。

`node dev/person_model_test.cjs` は公開モデル・作者のアニメ作例・人物写真をダウンロードする統合テストです。通常の回帰テストとは別に実行します。PlaywrightとEdgeが必要です。`PERSON_TEST_OUTPUT`でマスク画像の保存先を指定できます。
